# Crypto Skills for Python Devs

Skills for Claude and other LLMs/Agents to help users build projects in Python for blockchain networks.

## Available Skills

### Silverback

- **writing-bots**: Guide Claude through designing and implementing Silverback bots

## How to Use

1. In Claude.ai, go to Settings > Skills
2. Add this repository: https://github.com/ApeWorX/skills
3. Enable the skills you want (see skills.json for a machine-readable index)
